# 图表说明

前三张图来自 walking_async_final，第四张图来自 sensor_v2。绘图直接读取已存档的仿真记录。
每工况单一配对初始状态，无误差带、显著性检验或多种子统计。

1. 负载行走结果：比较10%/20%负载下固定参数和估计补偿控制。高度与平面速度RMSE使用第5至12秒。
2. 20%负载时序：展示完整12秒的速度、高度误差和估计载荷；黑线分别是指令速度、零高度误差和真实初始载荷。前4秒站立辨识，之后估计冻结。
3. 足端与停止：四脚几何中心高度减去球形脚半径22mm，作为几何净空代理；负值包含软接触压入。它不等同于接触力或地形安全裕度。下排展示故障注入后的速度和监督状态机。

完整八场景表在README；原始3000行/场景数据均保留。图中未重复绘制标称与附加推力轨迹，相关指标仍在完整评测中。
白底无网格，Arial Bold、粗实线、闭合框和朝内刻度按用户偏好导出。图中不放说明段落。
静态检查13 PASS、1 WARN、0 FAIL；WARN为展示尺寸大于常见论文栏宽。

## v2 状态估计与 ROS 2 停步

图 04 为仓库展示用四联图。每个工况一条轨迹，随机测量噪声种子 2026。

- a、b 使用 `reports/sensor_v2/loaded/trace.csv` 的 3000 条记录。a 比较机身高度估计与仿真真值，单位从 m 换算为 mm。b 比较前进速度估计、真值及第 4 秒开始的 0.10 m/s 指令。
- c、d 使用 `ros_zero`、`ros_timeout` 的各 2500 条记录。以独立 DDS 节点首次收到停步原因时附带的仿真时间对齐，展示前 0.4 秒到后 2 秒。c 画机身三维平移速度的模。d 根据控制循环记录画状态区间，状态变化可能早于 DDS 状态消息。全量轨迹和 DDS 记录随源码保留。
- 单次轨迹用于检查状态估计闭环和停步流程。图片未平滑、未降采样，统计指标及评分窗口见 v2 验收记录。
- PNG 300 dpi、SVG 和 PDF 随仓库交付。Python 脚本也支持本地导出 600 dpi TIFF。静态检查 13 PASS、1 WARN、0 FAIL，展示尺寸按 GitHub 页面设计。
